# 原神の自動取得間隔

原神プラグインの自動更新に用いる実効ロールポリシーは`genshinRefreshIntervalMinutes`です。既定10分、1〜1440分の整数のみ受け付けます。本人確認済みUIDの所有者の実効ポリシーを使います。

管理画面ではベースポリシーまたは個別ロールの「原神の自動取得間隔（分）」から変更します。ロールの優先度は既存の規則に従い、同じ優先度では短い間隔を採用します。長い間隔を個別に適用する場合は優先度を上げてください。ほかの数値ポリシーの最大値集約は変わりません。

レベル付きロールの定数・倍率設定でもこのキーを利用できます。定数は1〜1440分の整数、倍率は各到達段階で算出・切り捨てした結果が1〜1440分となる必要があります。ネイティブの検証とrole-levelのカタログ検証の両方で範囲外を拒否します。既存migrationやXP監査ログの仕様は変更しません。

管理画面で範囲やレベル数を変更し、倍率の結果が範囲外になった場合は、範囲先頭の値を有効な整数に補正して倍率の加算値を0に戻します。変更後のプレビューを確認してから保存してください。

対応する原神プラグインは更新確認を1分ごとに行います。最終取得・自動取得の最終試行から指定間隔が経過し、EnkaのTTLが切れている場合のみ取得します。失敗時は古いデータを残し、指定間隔より短く再試行しません。1回の最大取得数は50件なので、指定分数ちょうどの更新を保証する設定ではありません。

本体・管理画面・原神プラグインの対応版を組み合わせて導入してください。本体のキー追加だけでは旧プラグインの更新スケジュールは変わりません。本人確認コードの有効期限、最低60秒待機、公開設定、ランキング閲覧時に追加取得しない仕様は変更しません。
